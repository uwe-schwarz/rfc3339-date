# Local Geist fonts

The three unmodified WOFF2 files were copied from the npm `geist@1.7.2` release:

- `dist/fonts/geist-pixel/GeistPixel-Line.woff2`
- `dist/fonts/geist-pixel/GeistPixel-Square.woff2`
- `dist/fonts/geist-mono/GeistMono-Regular.woff2`

Source: https://github.com/vercel/geist-font

are preserved in `OFL.txt`. Renamed file paths do not change the font contents.
